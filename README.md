# 今天午饭吃什么

午饭时间不想再翻外卖软件时用的一个小工具。回答几个问题，吃正餐还是喝点什么、几个人、预算多少、能等多久、有没有忌口，它就从内置餐品库里挑几个出来。不合心意可以换一个、放进备选、收藏，或者撤销这次选择。

在线使用：https://xueer03135998-creator.github.io/lunch-helper/

## 大致能做什么

按人数、品类、口味、预算、送达时间和忌口筛选，价格区间也可以自己填。
收藏常吃的，把候选放进备选，记录最近吃过的餐品并默认避开。
自己添加餐品和忌口条目，不满意就重选或换一个。

## 数据在哪

页面是纯静态的，餐品库直接写在代码里，不请求后端，没有账号，也没有访问统计。收藏、历史、备选和自定义条目只存在当前浏览器的 localStorage 里（键名 `lunch-helper-v2`），不会上传；换浏览器、换设备或清理站点数据后会消失。餐品价格只是参考，实际以下单时的报价为准。

## 仓库里有什么

`index.html` 就是完整应用。前端用 React，构建时把样式、脚本、图片和字体都内联进这一个文件，约 3 MB，没有外部依赖，不用装包或跑构建。直接双击用浏览器打开就能用，路由走 hash，不依赖服务器；想按 HTTP 方式预览，在目录里跑 `python3 -m http.server 8000`，再访问 `http://localhost:8000`。

`.nojekyll` 只是让 GitHub Pages 跳过 Jekyll 处理。

这里只放构建产物，不含源码。

## 部署

GitHub Pages 发布 main 分支根目录。改动提交并 push 后会自动重建，访问链接不变。
